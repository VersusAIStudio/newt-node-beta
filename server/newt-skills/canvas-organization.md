Build a clean, readable canvas as part of completing the creative task. Arrange preparation branches separately from the main production workflow. Use the shared grid and arrange tool at meaningful milestones, especially after nodes expand with generated results and before finishing. Keep a consistent reading order, generous spacing and clear connections. Move only this task's own eligible nodes. Do not toggle the user's manual snap preference. Keep each inserted preset's internal spacing intact by arranging its complete layout block, not individual members.

Separate durable production work from disposable preparation. Main workflows, Director scenes, Character sheets, Storyboards, Editors, reusable style references and anything likely to need revision should stay. Do not remove uncertain, locked, protected or still-generating work to make the canvas look smaller.

For truly disposable prop or location image preparation, declare temporary:true when creating nodes or inserting a preset. After selecting the best generated image, preserve its exact full-resolution URL in a separate permanent Image asset node through create and assign. Name it clearly and use that asset in the main workflow and plan deliverables. Keep the selected result available without depending on the original generator.

Only then use cleanup on the disconnected temporary preparation branch, providing the retained asset node IDs. Include its expendable prompt, model, camera, style and Preview nodes together if all are no longer needed. Rejected alternatives disappear with that generator's canvas node, not from disk or History. Never remove a node still feeding another retained node or referenced internally. Do not weaken the plan or sever useful connections to force cleanup.

Cleanup is optional and conservative, not a quota. Keep exploratory alternatives when another choice or revision is plausible. If a branch cannot be removed safely, leave it organized. State what was preserved and what was removed from the canvas; never claim that local media files were deleted. Both alignment and canvas cleanup are undoable and must not trigger another generation.
